# 数据说明

- 10 条试跑共 60 次模型输出：10 个计划、50 张帧；各输出都有原始与压缩 reasoning。
- 5,000 候选任务：物理 1,250、动物 1,250、人物 1,250、交通工具 750、几何空间 500；包含多米诺 248 条。
- 4,940 条复用既有任务池，60 条新增几何候选。来源记录见 `data/tasks5000/provenance.json`；其中路径是历史来源标识，不要求这些历史目录存在。
- 候选 prompt 不等于已完成的教师轨迹，不是全新未见测试集。正式实验应进一步按动作族隔离 train/test，避免语义近重复泄漏。
- 79 条文本审核为较弱可用，建议生成后重点视觉检查。文本审核不保证动画质量。
- 完整教师轨迹的数值和几何可能有错；训练脚本只验证上下文、格式、token 长度与来源一致性，不保证物理正确。
- 压缩输入为实际模型上下文和原始 reasoning；不另提供最终答案。压缩不能凭空补推导，仍需抽查是否丢失关键结果或引入错误。
- 数据按白名单导出：保留请求正文、答案、reasoning、压缩正文和渲染结果；不包含认证头、服务器配置或密钥。
- 此仓库未另行授予基础模型或来源数据的授权；使用时遵循各自条款。
